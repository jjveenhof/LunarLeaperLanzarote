# Gravimetry -- La Corona lava tube

CG-5 gravity survey processing and the GPR-constrained tube inversion. This README is
only the front door -- **`REPRODUCE.md` is the real entry point**: the one command to run,
every thesis figure/table mapped to its producing script, and what was made by hand.
`CLAUDE.md` is the detailed pipeline reference; `DECISIONS.md` is the choices the code
cannot explain to you.

Quickest path in: `python run_pipeline.py`, then `python goldenmaster.py check` to confirm
nothing drifted. See `REPRODUCE.md` for everything past that.
